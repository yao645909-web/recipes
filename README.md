# 烘焙食譜 PWA

個人烘焙食譜本。食譜放在 Google 試算表，App 自動同步，離線也能看。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 頁面骨架 |
| `app.js` | 主程式：讀取試算表、列表、搜尋、詳細頁、設定 |
| `styles.css` | 樣式（支援深色模式） |
| `sw.js` | Service Worker：離線快取 |
| `manifest.json` | 讓安卓可以「安裝」到桌面 |
| `sample-recipes.csv` | 範例食譜，也可當試算表範本 |
| `icons/` | App 圖示 |

## 1. 準備試算表

食譜放在雲端硬碟「食譜」資料夾裡的 **食譜總表**（Google 試算表），由原本 74 個 Excel 檔整理而來，原檔沒有更動。

1. 打開「食譜總表」→ **檔案 → 共用 → 發佈到網路** → 選工作表 → 格式選 **逗號分隔值 (.csv)** → 發佈。
2. 複製網址（長得像 `https://docs.google.com/spreadsheets/d/e/.../pub?output=csv`）。

一列一道食譜，欄位：`名稱`（必填）、`分類`、`烤溫`、`倍數`、`材料`、`步驟`、`圖片`、`備註`、`來源`

- **材料**：一行一樣，`名稱 | 重量 | 其他倍數…`，例如 `A高粉 | 385 | 192.5`。開頭加 `#` 是分區，例如 `#主麵團`。
- **倍數**：材料每一欄的名稱，例如 `重量 | 3倍 | 5倍`。只有一欄時，App 提供 ×0.5～×3 自動換算。
- **步驟**：一行一步，保留原本的編號（例如 `1.A材拌勻…`），開頭加 `#` 是分區。
- 同一格裡換行：電腦用 Alt+Enter。
- **圖片**：貼雲端硬碟圖片的分享連結，並設成「知道連結的任何人」可檢視。
- **來源**：原本的 Excel 檔名，只是備查。

以後要新增食譜，直接在總表新增一列；或照舊做 Excel 檔，再請 Claude 幫忙加進總表。

> 注意：「發佈到網路」的網址不需要登入就能讀，但網址很長、別人猜不到。只有你知道網址就只有你看得到。

之後在 Google 試算表改食譜，App 裡按 ⟳ 就會更新。

## 2. 在電腦上測試

```bash
python -m http.server 8080
```

用瀏覽器打開 http://localhost:8080

## 3. 放上網路（免費，用 GitHub Pages）

PWA 一定要用 https 網址才能安裝到手機。

1. 到 github.com 註冊帳號，建立一個新的 repository（例如 `recipes`）。
2. 把這個資料夾的全部檔案上傳（網頁上可以直接拖拉上傳）。
3. Repository 的 **Settings → Pages**，Source 選 `main` branch，按 Save。
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/recipes/`。

## 4. 安裝到安卓手機

用手機 Chrome 打開上面的網址 → 右上角 ⋮ → **加到主畫面 / 安裝應用程式**。
打開 App → ⚙ 設定 → 貼上試算表 CSV 網址 → 儲存並同步。

## 更新程式

改了任何程式檔後，把 `sw.js` 第一行的 `VERSION` 加一（`v1` → `v2`），
手機下次打開時就會換成新版。
